# المنصة التعليمية — مذكرات وملخصات ودروس

منصة تعليمية متكاملة لمشاركة المذكرات والملخصات والدروس والفيديوهات، مع **سوق بائعين**،
كوبونات خصم، إشعارات، **تقييمات متعددة المحاور**، دعم لكل أنواع الملفات، بثوث مباشرة،
**تكامل Supabase**، وتصميم متجاوب لكل الأجهزة. مبنية بـ **HTML + JS + MJS** فقط وتُستضاف على **Netlify**.

## ✨ المميزات الرئيسية

### 🎨 تصميم متجاوب لكل جهاز
- **هاتف**: قائمة سفلية ثابتة، قائمة جانبية منسدلة شاملة للشاشة مع overlay، أزرار لمس كبيرة (44px+).
- **تابلت**: تخطيط عمودين، تصميم مدمج.
- **كمبيوتر**: سايدبار دائم للإدارة، شبكة متعددة الأعمدة.
- **لوحة الإدارة**: متجاوبة بالكامل على الهاتف (جداول قابلة للتمرير، نوافذ منبثقة كـ bottom sheet).

### 🏪 سوق البائعين (Marketplace)
- الأعضاء يقدمون طلبات انضمام كبائعين (طلاب/طالبات/معلمين/معلمات).
- الإدارة تراجع وتوافق/ترفض.
- البائع يرفع موادّه وبثوثه (تحتاج موافقة قبل النشر).
- نسبة عمولة قابلة للتعديل لكل بائع.
- تتبّع المبيعات والأرباح والمستحقات.
- طلب سحب الرصيد عند بلوغ الحد الأدنى.
- لوحة بائع مستقلة: مواد + بثوث + طلبات + أرباح.

### 🎯 تخصيص المحتوى حسب الجنس (ميزة مميزة)
- **محتوى حصري للطالبات فقط**: للمعلمات والطالبات اللاتي يرغبن بخصوصية أصواتهنّ أو صورهنّ.
- يعمل على: المواد (كل الأنواع) والبثوث المباشرة.
- الذكور لا يمكنهم رؤية أو شراء هذا المحتوى.
- خيار واضح في لوحة الإدارة ولوحة البائع مع شرح مفصّل.

### ⭐ نظام تقييمات متعدد المحاور (جديد!)
- **تقييم عام** (1-5 نجوم) + **4 محاور تفصيلية**:
  - جودة المحتوى
  - جودة الكتابة
  - القيمة مقابل السعر
  - سرعة التسليم
- **تصويت مفيد/غير مفيد** على كل تقييم.
- **تعديل التقييم** خلال 30 يوماً.
- **حذف التقييم** من قبل صاحبه.
- **ملخص مرئي**: توزيع النجوم + متوسط كل محور.
- **فرز**: الأحدث / الأكثر فائدة / الأعلى تقييماً / الأقل تقييماً.
- منع التكرار (مستخدم واحد = تقييم واحد لكل مادة).
- إشعار البائع عند تقييم جديد.

### 🏷️ نظام وسوم مرن
- وسوماً بأسماء وألوان مخصصة + دمج الوسوم.

### 📁 دعم كل أنواع الملفات
- Google Drive, YouTube, PDF, صور, فيديو MP4, صوت, روابط خارجية, Embed iframe.
- ملفات إضافية متعددة لكل مادة.

### 🎟️ كوبونات خصم
- نسبة مئوية أو مبلغ ثابت + حد أقصى للاستخدام + تاريخ انتهاء.
- كوبونات إدارية + كوبونات بائعين (بسقف أقصى للخصم).

### 📡 البثوث المباشرة
- جدولة بثوث على Google Meet / Zoom / YouTube Live.
- البائعون ينشئون بثوثهم (تحتاج موافقة الإدارة).
- إمكانية تخصيص البث للطالبات فقط.

### 💳 نظام الدفع
- الدفع عبر **بنفت** (BenefitPay) — رقم هاتف لتحويل المبلغ.
- رفع صورة الإيصال أو كتابة رقم العملية.
- المراجعة اليدوية من الإدارة + تفعيل تلقائي.

### 🗄️ نظام تخزين ذكي (جديد!)
- **Supabase** أولاً (إذا ضُبطت متغيرات البيئة) — تخزين دائم وموثوق.
- **Netlify Blobs** كـ fallback تلقائي.
- **JSON محلي** للمعاينة المحلية.
- التبديل تلقائي بدون تغيير الكود.
- صفحة "حالة النظام" في لوحة الإدارة تعرض الوضع الحالي.

### 🎨 تخصيص كامل
- الشعار، اللون الرئيسي، وضع الخلفية، CSS مخصص، إظهار/إخفاء الأقسام، شريط إعلان.

## 🚀 الاستخدام

### معاينة محلية سريعة
```bash
netlify dev
```
افتح `http://localhost:8888` — يعمل بـ JSON محلي تلقائياً.
- **الإدارة**: `admin/login.html` بـ `admin@platform.site` / `admin123`

### النشر على Netlify مع Supabase
1. ارفع المشروع إلى GitHub واربطه بـ Netlify.
2. أنشئ مشروع Supabase وطبّق `supabase_schema.sql` (راجع `SUPABASE_SETUP.md`).
3. اضبط متغيرات البيئة في Netlify:
   - `SUPABASE_URL` — رابط مشروع Supabase
   - `SUPABASE_SERVICE_KEY` — مفتاح service_role (سرّي!)
   - `NETLIFY_AUTH_SECRET` — سرّ توقيع التوكنات (أي نص عشوائي طويل)
   - `ADMIN_EMAIL` — بريد الإدارة (افتراضي: `admin@platform.site`)
   - `ADMIN_PASSWORD` — كلمة مرور الإدارة (افتراضي: `admin123`)
4. انشر — لا حاجة لخطوة build.

## 🔑 بيانات الإدارة الافتراضية
- **البريد**: `admin@platform.site`
- **كلمة المرور**: `admin123`
- غيّرها من الإعدادات أو عبر متغيرات البيئة.

## 🗄️ قاعدة البيانات
- **Supabase** (موصى به للإنتاج) — راجع `SUPABASE_SETUP.md`.
- **Netlify Blobs** — fallback تلقائي.
- **JSON محلي** — للمعاينة.
- لا توجد بيانات وهمية — فقط حساب الإدارة الافتراضي.

## 🔧 الإصلاحات في هذا الإصدار (v4.0.0)

1. **القائمة المنسدلة للهاتف**: شاشة كاملة + overlay + زر إغلاق + نسخ أزرار الإجراءات.
2. **صفحة تسجيل دخول المسؤول**: مدمجة بالكامل (لا placeholder) + إظهار/إخفاء كلمة المرور + تلميحات.
3. **لوحة الإدارة**: شاشة تحقق قبل الظهور (لا وميض) + تحقق من الجلسة عبر الخادم.
4. **تجاوب لوحة الإدارة على الهاتف**: جداول، نوافذ منبثقة (bottom sheet)، أحجام خطوط، تبويبات.
5. **نظام التقييمات**: متعدد المحاور + تصويت + تعديل + حذف + ملخص مرئي + فرز.
6. **Supabase**: طبقة كاملة + fallback ذكي + مخطط SQL + دليل إعداد.
7. **تثبيت السر**: إصلاح مشكلة تغير SECRET بين الطلبات في المعاينة المحلية.
